# SmartEnergy AI

**Predictive Electricity Consumption & Energy Waste Analyzer**

A Streamlit + Scikit-learn project for the Thiranex task "Predictive Modeling Using Machine Learning".

## Features
- Daily electricity consumption prediction
- Random Forest Regression
- Linear Regression comparison
- Energy-waste classification
- Confusion matrix
- ROC curve and ROC-AUC
- MAE, RMSE and R²
- Feature importance
- Personalized energy-saving recommendations
- Professional blue-first dashboard

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

The included `energy_data.csv` is a synthetic educational dataset. Replace it with properly collected and consented meter data for a real deployment.
